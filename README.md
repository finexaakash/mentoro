# 📚 EdTech Platform

A full-stack EdTech platform designed for teachers and learners to manage and access educational resources efficiently. The platform provides a smooth and responsive learning experience with optimized performance and secure resource management features.

---

## 🚀 Features

- Teacher and learner authentication system
- Upload and manage educational resources
- Support for:
  - Notes
  - Books
  - Videos
  - Educational links
- Edit and organize uploaded content
- Daily upload limit control
- Protected routes for secure access
- Pagination for efficient data loading
- localStorage-based caching to reduce unnecessary API calls
- Request locking mechanism for optimized performance
- Fully responsive UI using Tailwind CSS

---

## 🛠️ Tech Stack

### Frontend
- React.js
- Tailwind CSS
- JavaScript

### Backend
- Node.js
- Express.js

### Database
- MongoDB

---

## ⚡ Performance Optimizations

- Implemented caching using localStorage
- Reduced redundant API requests
- Added request locking for preventing duplicate calls
- Optimized pagination for faster content loading

## 🔐 Security Features
